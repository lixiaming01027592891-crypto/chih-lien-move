# 台中公司搬遷的資訊設備怎麼搬？伺服器機櫃、網路復機與文件保密的實務流程

企業搬家與住家搬家最大的差別，不在東西多寡，而在於「停下來的每一小時都有代價」。辦公室裡最怕出狀況的其實只有兩類東西：一類是資訊設備，包含伺服器、網路機櫃、交換器、無線基地台、印表機與同仁的電腦；另一類是機密文件，包含合約正本、人事資料、客戶名單與財會憑證。這兩類東西的共通點是，**壞了不只是重買一台的成本，資料回不來、文件外流出去，損失沒辦法用搬運費來衡量**。

這篇文章把公司搬遷中最容易被輕忽的兩件事，依照「盤點、斷線、搬運、復機、交接」的順序整理成可以照著跑的流程。若您要先看整體的空間規劃與人員動員，可以搭配[企業搬遷規劃完整指南](/blog/taichung-office-factory-260628/)一起閱讀。

## 為什麼資訊設備要單獨拉出來規劃？

一般辦公傢俱只要包覆到位、固定妥當、搬運不碰撞，到了新址擺回去就能用。資訊設備則多了三層變數：

- **它有先後順序**：不是搬到就能用。新址的電力迴路、網路線路施工、對外電路開通、伺服器上架順序，一環扣一環，任何一環沒到位，後面全部卡住。
- **它有不可回復性**：硬碟怕震動、怕異常斷電，一旦資料毀損，事後補救的時間與費用往往遠高於整趟搬遷的成本。
- **它有責任歸屬**：機密文件在搬運途中由誰保管、由誰簽收、封條有沒有動過，都需要留下可查的紀錄。

因此，資訊設備的搬遷本質上是一個小型專案。**搬家公司負責的是物理搬運與防護，關機、拆線、復機、測試則應由公司的資訊人員或委外維護廠商主導**，兩邊的分工界線要在搬遷前就談清楚，不要到了現場才互相等待。

## 搬遷前：盤點資產、拍照存證、畫一張現況圖

資訊設備最常見的災難不是摔壞，而是「線接不回去」。搬遷前建議完成這幾件事：

1. **建立資產清單**：主機、螢幕、伺服器、交換器、路由器、印表機、UPS 不斷電系統，逐項記錄型號、財產編號與原本使用者或擺放位置。
2. **線材拍照與貼標**：機櫃背面、主機背板在拆線前先拍照，再把每一條線的兩端貼上同號碼標籤。這一步花的時間，會在新址復機時全部賺回來。
3. **繪製配置對照圖**：舊址哪個座位對應新址哪個座位、機櫃內設備由上而下的排列順序，畫成一張圖，現場任何人拿到都看得懂。
4. **完成一次完整備份**：搬遷前務必做好資料備份並確認可還原，備份媒體與主機分開運送，不要放在同一個箱子裡。
5. **確認新址基礎建設**：電力容量、插座位置與數量、網路佈線、機房空調與門禁，這些都要在搬遷日之前驗收完成。

新址的網路與電路開通往往需要事先申請與排施工日，是整份時程表中最需要提早的一項。想同時把淡旺季與可用檔期一起排進去，可以參考[搬家怎麼挑日子](/blog/taichung-move-date-scheduling-20260721/)的安排思路。

## 停機時間怎麼壓縮？把順序排出來

多數公司希望「週五下班搬、週一上班能用」。要做到這件事，關鍵在順序而不在速度：

- **分批而非一次全搬**：把設備分成「必須最先復機」與「可以晚一點」兩群。核心網路設備、伺服器、財會與生產相關的終端優先；周邊印表機、備品、倉儲物資可以往後排。
- **先關使用者端，再關核心**：依序關閉個人電腦、周邊設備，最後才是伺服器與網路核心設備，並依正常程序關機，避免直接斷電。
- **新址則反過來**：先送電、先通網路、先上架核心設備並確認連線，再讓一般座位的設備進場，避免大批人力到了現場卻無網可測。
- **保留一段緩衝**：把測試與排除異常的時間排進表裡，不要讓復機時間直接壓在上班日的第一個小時。

## 搬運當天：機櫃與主機的防護重點

物理搬運這段，是搬家團隊的專業所在，但有幾個原則值得事先確認：

- **機櫃通常要清空再搬**：設備逐台下架、個別包覆，機櫃本體另外搬運。整櫃連同設備一起移動，重心高又容易在轉彎與上下坡時晃動。
- **防震優先於防刮**：主機、伺服器、UPS 的內部零件怕的是震動與衝擊，包材要有足夠緩衝厚度，車內也要確實固定，不要只用布巾覆蓋。
- **直立與朝向要維持**：部分設備有固定的擺放方向，包裝時就標示清楚，避免搬運人員為了堆疊而翻轉。
- **螢幕與玻璃面板單獨處理**：面板不受壓、不疊放重物，這與精緻搬家的[包覆與防護工法](/blog/taichung-premium-protection-260708/)是同一套邏輯。
- **貨梯與動線先確認**：機櫃、保險箱、大型印表機的尺寸與重量，要先確認電梯載重、門寬與大樓的搬運時段規定，並評估卸貨點到車位的距離，相關判斷可參考[搬運車停放與巷弄動線](/blog/taichung-move-parking-access-20260725/)。

## 紙本與機密文件的保密鏈：從封箱到簽收

資訊安全不是只有伺服器的事。搬遷期間紙本文件離開了原本的櫃子與門禁，反而是風險最高的時候。建議建立一條完整的保密鏈：

1. **先分級再打包**：把文件分成一般、內部、機密三級。機密等級的文件（人事、合約、財會、客戶個資）不與一般物品混裝。
2. **專箱、封條、編號**：機密文件使用獨立箱體，封口貼上封條並編號，箱外只寫編號不寫內容。
3. **指定專責保管人**：由公司內部指派人員全程隨行或親自運送，不要交由不特定人員經手。
4. **交接留紀錄**：出發前與抵達後各清點一次箱數與封條完整性，雙方簽名確認。這個做法與搬家當天的[物品清點與驗收](/blog/taichung-move-checklist-verify-20260727/)是同一種思維，只是對象換成了文件。
5. **淘汰文件走正規程序**：搬遷是清理舊檔案的好時機，但確定不再保留的機密文件應以碎紙或委外銷毀處理並取得證明，不要直接當一般回收丟棄。
6. **同步處理數位權限**：門禁卡、離職人員帳號、共用資料夾權限，趁搬遷一併檢視，新址的實體門禁與機房上鎖規則也要一起定下來。

## 新址復機與驗收：一項一項確認

到了新址，不要只確認「東西都到了」，要確認「東西都能用」：

- **對照資產清單逐項核對**，缺件或外觀受損當場拍照記錄，不要等隔天才提。
- **依配置圖上架與接線**，接完先做通電測試，再做網路連線測試，最後才做應用系統測試。
- **確認備份機制恢復運作**，排程、還原點與異地備份都要重新確認一次，不要以為搬過去就會自己跑。
- **請各部門實際操作一輪**：列印、掃描、共用資料夾、內部系統、電話與視訊會議設備，由使用者親自驗過才算完成。
- **保留一份異常清單**：當天無法解決的項目集中列管，指定負責人與完成時間。

若搬運過程中真的發生設備受損，處理方式與責任認定就要回到事前簽訂的契約與保險條款，這部分可以參考[搬家契約、保險與物品毀損理賠](/blog/taichung-move-insurance-contract-20260724/)的說明，在簽約階段就把貴重設備的申報方式問清楚。

## 常見的三個疏漏

- **只搬設備、沒搬「環境」**：新址沒有預留足夠插座與網路孔，導致現場拉延長線應急，既不安全也不穩定。
- **沒有人統籌**：搬家團隊、資訊人員、房東或管理室各做各的。建議指派一位總窗口，所有現場決策由他確認。
- **忘了對外通知**：公司地址變更後，發票與登記資料、往來廠商、客戶、銀行、電信與宅配收件地址都要更新，這份清單最好在搬遷前就列好逐項打勾。

## 結語：把「能不能用」當成搬遷完成的標準

公司搬遷的成敗，不在於傢俱擺得多整齊，而在於同仁隔天早上坐下來，電腦開得起來、網路連得上、檔案找得到、文件一份不少。資訊設備與機密文件之所以要單獨規劃，正是因為它們決定了業務能多快回到正軌。
